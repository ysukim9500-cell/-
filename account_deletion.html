본 페이지는 법인차량 운행기록 관리 앱 ATEC Driving 사용자의 계정 및 데이터 삭제 방법을 안내합니다.

1. 데이터 일부 삭제 (계정 유지)

앱에 로그인한 상태에서 개별 운행기록을 직접 삭제할 수 있습니다.

  1. 앱 실행 후 로그인
  2. 운행 내역에서 삭제할 기록 선택 → 상세 화면의 삭제 버튼
  3. 확인하면 해당 운행기록(경로·위치·계기판 등)이 클라우드에서 즉시 삭제됩니다

2. 계정 및 전체 데이터 삭제

계정과 모든 데이터의 완전 삭제를 원하시면 아래 이메일로 요청해 주세요.

  1. 이메일: ysukim@atecmobility.com
  2. 제목: [ATEC Driving] 계정 삭제 요청
  3. 본문에 로그인 아이디와 차량번호를 기재
  4. 요청 확인 후 영업일 기준 7일 이내 계정과 관련 데이터를 모두 삭제하고 회신드립니다

3. 삭제되는 데이터 / 보관되는 데이터

구분내용
삭제되는 데이터계정 정보(아이디·이름·차량번호), 운행기록(일시·출발/도착지·계기판·목적), 위치·이동경로, 프로필(소속·부서·직책·차종)
보관되는 데이터없음. 단, 관계 법령에 따라 보존이 필요한 경우 해당 법정 기간 동안만 보관 후 파기합니다.
